About Vedic review

Click a character to rate vertical spacing and horizontal placement independently. All cells stay white. Small colored markers indicate non-okay ratings: red − for too close, amber + for too far away, blue ← for too far left, purple → for too far right, and gray ? for unsure. Vertical markers sit at the top left; horizontal markers at the top right. Okay ratings have no marker. Dashed borders mean at least one axis is unreviewed or unsure; a solid border with no markers means both axes are explicitly okay. Only explicit reviews are exported. Reviews save in this browser.

Choose a script, combination group, accent, and font size in the pinned toolbar. Export JSON includes exact Unicode text, decisions, font size, browser, and font fingerprint. Select a character and use “Edit selected” to try it in a native text area.

On a focused character, use arrow keys to navigate, Home/End for the first or last sample, and Page Up/Down to move by a screenful. Press 1 for too close, 2 for okay, 3 for too far away. Press 4 for too far left, 5 for horizontally okay, 6 for too far right, or E to edit. The dialog lets you mark either axis unsure and add a note. Rate both axes independently; leaving one blank does not mark it okay. Enter opens the choices. Shortcuts do not run while typing in a field. View settings and the selected character are restored from browser storage.

Columns keep the same character order. Bare consonants come before vowel-sign rows; each accent has its own row. Click a row heading to select that row. Shift-click or Shift+arrows selects a rectangle; Ctrl/Cmd-click toggles individual cells. Ctrl/Cmd+A selects the displayed cells; Escape clears selection. Ratings 1–6 apply to every selected cell. Click a cell for the rating dialog; Enter opens it for the current selection. Notes in the dialog also apply to all selected cells. Edit applies to the focused cell only.

The corpus uses distinct native keyboard vowels and consonants (including Tamil superscripted consonants), native vowel signs and diacritics, and ordered two-consonant combinations with vowel signs. These are mechanical combinations, not all linguistically valid syllables. Only Indic scripts declaring Vedic accent support are listed. Add longer conjuncts and words through Custom.
