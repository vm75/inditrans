About Inditrans Demo

Compare how the same text renders in different scripts and fonts. Transliterates live using Inditrans, including Vedic accents.

Fonts and the Inditrans engine load over the internet. Font selection affects appearance only; the Unicode text remains unchanged.

Your settings and both text panes are saved in this browser automatically.

This demo uses the fixed Inditrans release shown in the version badge.

ASCII → script mode types into the input script using the shortcuts shown on the keyboard. Vowels become signs immediately after consonants (ki → कि); otherwise they are independent. Use : before a vowel to force its independent form (k:i → कइ), backtick (`) for virama (k`Sh → क्ष), and ; between shortcuts to separate them (k;h → कह, kh → ख). Dot-prefixed signs also work explicitly. Backslash escapes the next ASCII character; pasted text and your system input method are left unchanged.

If a font lacks a glyph or accent, the demo uses downloaded Indic and Roman fallback fonts. Allow fonts.googleapis.com and fonts.gstatic.com if characters appear as boxes. For precise font comparisons, check the browser's rendered-font inspector.

Enter a Google Fonts family name, or provide a full CSS URL to load any web font. Loaded fonts are added to both dropdowns (marked manual).

Loaded Fonts

Font faces registered in document.fonts, grouped by family. Green = loaded, yellow = partial or loading, grey = idle, red = error. This shows download status; use the browser's rendered-font inspector to see which fonts draw a glyph.
